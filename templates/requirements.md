# 要求・要件定義書 (Requirements & Specifications)

## 技術スタック・制約 (Technical Stack & Constraints)
プロジェクトで採用する技術、UIの形態、外部システム等を定義します。

| 項目 | 内容 | 備考 |
| :--- | :--- | :--- |
| 使用言語 | [TypeScript / Python / Rust 等] | バージョン、主要フレームワーク含む |
| UI形態 | [CLI / Web / モバイル / なし 等] | 主要なインターフェース |
| データストア | [JSONファイル / SQLite / PostgreSQL / なし 等] | 外部DBや永続化手法 |
| 外部システム | [なし / 外部API名 等] | 連携が必要なシステム |

## 要求セクション (Requirements)
ユーザーの「やりたいこと（抽象的な目的）」を ID-XXX 形式で定義します。

| ID | 内容 | 背景・詳細 | 状態 | 後継/関連ID |
| :--- | :--- | :--- | :--- | :--- |
| REQ-001 | [一文で記述] | [なぜ必要か、具体的な条件] | 新規/検討中/承認済み/実装済み/廃止/分割済 | [REQ-XXX] |

## 詳細要件セクション (Specifications)
要求を実現するための「テスト可能な具体的な動作」を定義します。

| ID | 親要求ID | 内容 | 優先度 | 状態 |
| :--- | :--- | :--- | :--- | :--- |
| SPEC-001 | REQ-001 | [主体]は、[条件]のとき、[動作]ができること | 高/中/低 | 未着手/分析中/定義済み/実装済み |

## 変更履歴 (Change History)
要求の大きな変更（追加、廃止、分割、統合）の経緯を記録します。

| 日付 | 種別 | 対象ID | 内容・理由 |
| :--- | :--- | :--- | :--- |
| YYYY-MM-DD | 追加/変更/廃止/分割/統合 | REQ-XXX | [変更の理由と、どのIDに引き継がれたか] |
